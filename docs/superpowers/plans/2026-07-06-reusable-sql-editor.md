# Reusable `SqlEditor` Component Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a reusable, schema-fed Monaco SQL editor for loom's Yew/WASM UI, proven in isolation via the component gallery, with a pure unit-tested completion engine.

**Architecture:** Follow loom's pure/interop split — the completion *logic* (`sql_completions`, `cursor_context`) lives in the lint-clean, `rust_test`'d `loom_ui_core`; a thin yew-0.21 `SqlEditor` component in `loom_ui_components` wraps rust-monaco's raw `api`/`sys` bindings (no `yew-components`, which pins yew 0.23) and registers a completion provider that calls the pure engine. Monaco ships vendored inside the crate via wasm-bindgen module snippets — no CDN, no network at build.

**Tech Stack:** Rust → `wasm32-unknown-unknown`, Yew 0.21, `stylist`, `monaco` 0.7.0 (`api` + `workers` features), wasm-bindgen `=0.2.126`, buck2 + wasm-bindgen-cli bundling, reindeer for third-party import.

**Spec:** `docs/superpowers/specs/2026-07-06-reusable-sql-editor-design.md`

## Global Constraints

- **yew = "0.21"** (features `["csr"]`) — do NOT pull yew 0.23; never enable monaco's `yew-components` feature.
- **wasm-bindgen = "=0.2.126"** — exact pin (crate must equal `//tools:wasm-bindgen` CLI version or the glue panics at load).
- **monaco = "0.7.0"**, `default-features` only (`api` + `workers`); NOT `yew-components`.
- **edition = "2024"** on all loom-ui targets.
- **No inline `#[test]`** in any `src/**.rs` — the `no-inline-tests` prek hook fails the build. Unit tests are sibling `tests/<name>.rs` files wired as their own `rust_test` target in `src/ui/BUCK`.
- **Pure logic → `loom_ui_core`** (lint-clean, tested). View-glue (`html!`/`css!`) → `loom_ui_components` (crate-level `#![allow(clippy::pedantic, clippy::restriction)]`, gallery-verified — buck2 `rust_test` has no DOM).
- **Hermetic:** no CDN, no network fetch of Monaco assets; everything ships through the wasm-bindgen bundle.
- **Don't pipe `buck2 test`/`bxl` through `tail`/`head`** — redirect to a file and grep it.
- **Adding a dep** requires a `Cargo.lock` refresh + `./tools/buckify.sh` or the `reindeer-check` hook fails; after any `reindeer update` run the **full** `buck2 build //src/...` (a green per-crate build is not enough — feature unification is graph-wide).
- **Stylist scopes selectors as descendant rules** (`.<hash> .foo`) — prefix structural class names (e.g. `sqled-*`) so generic names don't leak into nested styled components.

```rust
use web_sys::HtmlElement;

/// Reusable Monaco-backed SQL editor. Minimal (empty) in this spike; props and
/// completion are added in later tasks.
#[styled_component(SqlEditor)]
pub fn sql_editor() -> Html {
    let node = use_node_ref();
    // Keep the editor alive for the component's lifetime; drop on unmount.
    let editor = use_mut_ref(|| None::<CodeEditor>);

    {
        let node = node.clone();
        let editor = editor.clone();
        use_effect_with(node, move |node| {
            let el: HtmlElement = node.cast().expect("sql-editor node is an HtmlElement");
            let opts = CodeEditorOptions::default()
                .with_language("sql".to_owned())
                .with_builtin_theme(BuiltinTheme::VsDark)
                .with_automatic_layout(true);
            *editor.borrow_mut() = Some(CodeEditor::create(&el, Some(opts)));
            move || {
                // Dispose the editor when the component unmounts.
                editor.borrow_mut().take();
            }
        });
    }

    let css = css!(
        r#"
        .sqled-host { width: 100%; height: 320px; border: 1px solid var(--loom-border); border-radius: var(--loom-radius); overflow: hidden; }
        "#
    );
    html! { <div class={css}><div ref={node} class="sqled-host" /></div> }
}
```

```rust
//! Pure, DOM-free SQL completion engine. The `SqlEditor` component
//! (`loom_ui_components`) feeds cursor context in and maps the results to
//! Monaco completion items; all behaviour and filtering lives here so it is
//! unit-testable without a browser.

#[derive(Clone, PartialEq, Eq, Debug, Default)]
pub struct CompletionSchema {
    pub tables: Vec<CompletionTable>,
}

#[derive(Clone, PartialEq, Eq, Debug)]
pub struct CompletionTable {
    pub schema: Option<String>,
    pub name: String,
    pub columns: Vec<CompletionColumn>,
}

#[derive(Clone, PartialEq, Eq, Debug)]
pub struct CompletionColumn {
    pub name: String,
    pub ty: String,
}

#[derive(Clone, PartialEq, Eq, Debug)]
pub enum SuggestionKind {
    Keyword,
    Table,
    Column,
}

#[derive(Clone, PartialEq, Eq, Debug)]
pub struct Suggestion {
    pub label: String,
    pub kind: SuggestionKind,
    pub detail: Option<String>,
    pub insert_text: String,
}

/// The static keyword set offered on unqualified completion.
pub const SQL_KEYWORDS: &[&str] = &[
    "SELECT", "FROM", "WHERE", "GROUP BY", "ORDER BY", "HAVING", "JOIN",
    "LEFT JOIN", "INNER JOIN", "ON", "AS", "AND", "OR", "NOT", "IN", "IS",
    "NULL", "LIMIT", "DISTINCT", "WITH", "UNION ALL", "INSERT INTO", "VALUES",
];

fn starts_with_ci(haystack: &str, prefix: &str) -> bool {
    haystack.to_ascii_lowercase().starts_with(&prefix.to_ascii_lowercase())
}

/// Suggestions for the given cursor context.
/// - `qualifier = Some(t)` → columns of the table named `t` (case-insensitive),
///   filtered by `prefix`; empty if no such table.
/// - `qualifier = None` → table names + all column names + SQL keywords,
///   each filtered by `prefix`. Order: tables, columns, keywords.
#[must_use]
pub fn sql_completions(
    schema: &CompletionSchema,
    prefix: &str,
    qualifier: Option<&str>,
) -> Vec<Suggestion> {
    if let Some(q) = qualifier {
        let Some(table) = schema
            .tables
            .iter()
            .find(|t| t.name.eq_ignore_ascii_case(q))
        else {
            return Vec::new();
        };
        return table
            .columns
            .iter()
            .filter(|c| starts_with_ci(&c.name, prefix))
            .map(|c| Suggestion {
                label: c.name.clone(),
                kind: SuggestionKind::Column,
                detail: Some(c.ty.clone()),
                insert_text: c.name.clone(),
            })
            .collect();
    }

    let mut out = Vec::new();
    for t in &schema.tables {
        if starts_with_ci(&t.name, prefix) {
            out.push(Suggestion {
                label: t.name.clone(),
                kind: SuggestionKind::Table,
                detail: t.schema.clone(),
                insert_text: t.name.clone(),
            });
        }
    }
    for t in &schema.tables {
        for c in &t.columns {
            if starts_with_ci(&c.name, prefix) {
                out.push(Suggestion {
                    label: c.name.clone(),
                    kind: SuggestionKind::Column,
                    detail: Some(c.ty.clone()),
                    insert_text: c.name.clone(),
                });
            }
        }
    }
    for kw in SQL_KEYWORDS {
        if starts_with_ci(kw, prefix) {
            out.push(Suggestion {
                label: (*kw).to_owned(),
                kind: SuggestionKind::Keyword,
                detail: None,
                insert_text: (*kw).to_owned(),
            });
        }
    }
    out
}
```

- [ ] **Step 3: Implement `cursor_context`**

Append to `src/ui/src/completion.rs`:

```rust
fn is_ident_char(c: char) -> bool {
    c.is_ascii_alphanumeric() || c == '_'
}

/// Extract `(prefix, qualifier)` at a byte `offset` into `text`.
/// `prefix` is the identifier ending at the cursor; `qualifier` is the
/// identifier immediately before a `.` that precedes the prefix, if present.
/// ASCII-identifier oriented (SQL identifiers); `offset` is clamped to `text`.
#[must_use]
pub fn cursor_context(text: &str, offset: usize) -> (String, Option<String>) {
    let offset = offset.min(text.len());
    let bytes = text.as_bytes();

    // Walk left over identifier chars to find the prefix start.
    let mut start = offset;
    while start > 0 && is_ident_char(bytes[start - 1] as char) {
        start -= 1;
    }
    let prefix = text[start..offset].to_owned();

    // If a '.' immediately precedes the prefix, read the qualifier before it.
    let qualifier = if start > 0 && bytes[start - 1] == b'.' {
        let mut qstart = start - 1;
        while qstart > 0 && is_ident_char(bytes[qstart - 1] as char) {
            qstart -= 1;
        }
        let q = &text[qstart..start - 1];
        if q.is_empty() { None } else { Some(q.to_owned()) }
    } else {
        None
    };

    (prefix, qualifier)
}
```

```rust
    /// CSS height, e.g. "320px". Defaults to 320px.
    #[prop_or_default]
    pub height: Option<AttrValue>,
}

#[styled_component(SqlEditor)]
pub fn sql_editor(props: &SqlEditorProps) -> Html {
    let node = use_node_ref();
    let editor = use_mut_ref(|| None::<CodeEditor>);
    // Hold the on_did_change subscription so it isn't dropped (which would
    // unsubscribe). `IDisposable` from monaco.
    let sub = use_mut_ref(|| None::<monaco::sys::IDisposable>);

    // Mount: create the editor, seed the model, subscribe to changes.
    {
        let node = node.clone();
        let editor = editor.clone();
        let sub = sub.clone();
        let on_change = props.on_change.clone();
        let initial = props.value.to_string();
        let read_only = props.read_only;
        use_effect_with(node, move |node| {
            let el: HtmlElement = node.cast().expect("sql-editor node is an HtmlElement");
            let model = TextModel::create(&initial, Some("sql"), None)
                .expect("create SQL text model");
            let opts = CodeEditorOptions::default()
                .with_language("sql".to_owned())
                .with_builtin_theme(BuiltinTheme::VsDark)
                .with_automatic_layout(true)
                .with_model(model.clone());
            let ed = CodeEditor::create(&el, Some(opts));

            // Emit on_change with the model's current text on every edit.
            let cb_model = model.clone();
            let disposable = ed.on_did_change_model_content(move |_ev| {
                on_change.emit(cb_model.get_value());
            });
            *sub.borrow_mut() = Some(disposable);
            let _ = read_only; // applied via options in reconciliation if supported
            *editor.borrow_mut() = Some(ed);

            move || {
                sub.borrow_mut().take();     // unsubscribe
                editor.borrow_mut().take();  // dispose editor
            }
        });
    }

    // Controlled-with-guard: only force-set the model when the incoming prop
    // differs from the editor's current text (avoids fighting the buffer/cursor
    // during normal typing).
    {
        let editor = editor.clone();
        use_effect_with(props.value.clone(), move |value| {
            if let Some(ed) = editor.borrow().as_ref() {
                if let Some(model) = ed.get_model() {
                    if model.get_value() != value.to_string() {
                        model.set_value(&value.to_string());
                    }
                }
            }
            || ()
        });
    }

    let h = props.height.as_ref().map_or("320px".to_owned(), std::string::ToString::to_string);
    let css = css!(
        r#"
        .sqled-host { width: 100%; border: 1px solid var(--loom-border); border-radius: var(--loom-radius); overflow: hidden; }
        "#
    );
    html! {
        <div class={css}>
            <div ref={node} class="sqled-host" style={format!("height:{h};")} />
        </div>
    }
}
```

If `TextModel::create` / `with_model` / `on_did_change_model_content` / `get_value` / `set_value` differ from the spike notes, adjust to the recorded signatures (e.g. value read may be `ed.get_model().unwrap().get_value()`).

```rust
use wasm_bindgen::JsCast;

// Inside the mount effect, after creating the editor. Capture the schema by value.
let schema = props.schema.clone();
let provider = monaco::sys::languages::CompletionItemProvider::from(JsValue::from(js_sys::Object::new()));
let provide = Closure::wrap(Box::new(
    move |model: monaco::sys::editor::ITextModel, position: monaco::sys::Position| -> JsValue {
        let text = model.get_value();
        let offset = model.get_offset_at(&position) as usize;
        let (prefix, qualifier) = cursor_context(&text, offset);
        let items = sql_completions(&schema, &prefix, qualifier.as_deref());

        let arr = js_sys::Array::new();
        for s in items {
            let item = js_sys::Object::new();
            let _ = js_sys::Reflect::set(&item, &"label".into(), &s.label.clone().into());
            let _ = js_sys::Reflect::set(&item, &"insertText".into(), &s.insert_text.into());
            let kind = match s.kind {
                SuggestionKind::Keyword => 17, // monaco CompletionItemKind.Keyword
                SuggestionKind::Table => 7,    // .Class (table)
                SuggestionKind::Column => 5,   // .Field (column)
            };
            let _ = js_sys::Reflect::set(&item, &"kind".into(), &JsValue::from_f64(kind as f64));
            if let Some(d) = s.detail {
                let _ = js_sys::Reflect::set(&item, &"detail".into(), &d.into());
            }
            arr.push(&item);
        }
        let list = js_sys::Object::new();
        let _ = js_sys::Reflect::set(&list, &"suggestions".into(), &arr);
        list.into()
    },
) as Box<dyn FnMut(monaco::sys::editor::ITextModel, monaco::sys::Position) -> JsValue>);
let _ = js_sys::Reflect::set(
    provider.as_ref(),
    &"provideCompletionItems".into(),
    provide.as_ref().unchecked_ref(),
);
let reg = monaco::sys::languages::register_completion_item_provider("sql", &provider);
// Keep both the closure and the registration alive; dispose on unmount.
*completion.borrow_mut() = Some((provide, reg));
```
