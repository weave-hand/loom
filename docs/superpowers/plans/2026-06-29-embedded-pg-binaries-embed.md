# Embed + self-extract PG binaries — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bake the PostgreSQL distribution into the binary via `include_bytes!` and self-extract it to a content-addressed cache at startup, so an embedded loom boot needs no PG binaries pre-staged on disk.

**Architecture:** A new gated crate `managed-postgres-embed` embeds the PG `.tar.gz` (`include_bytes!(env!("LOOM_PG_TARBALL"))`, fed by a new `:postgres-tarball` buck `http_file`), and `extract_pg()` decompresses (`flate2`) + untars (`tar`) it to `<LOOM_DATA_PATH>/cache/pg-<version>/` with a lock-free temp-dir→`rename()` publish. The base `managed-postgres` crate is untouched, so the 11.7 MB stays out of lean service binaries. Runtime/binary integration is slice 3's job.

**Tech Stack:** Rust, buck2 (`http_file`, `$(location)`→`env`, `loom_fixture_test`), `flate2` + `tar`, BuildBuddy RE.

## Global Constraints

- **Separate crate, not a feature variant.** The embed lives in a NEW crate `src/services/managed-postgres-embed/`. Do NOT add a feature/embed module to `managed-postgres` (a binary pulling both the lean crate via `service_runtime` and an embed variant would link two `managed_postgres` copies — a duplicate-crate conflict).
- **Base `managed-postgres` stays untouched** — no `tar`, no tarball, no new deps. It must remain lean for the zero-pool worker.
- **`include_bytes!(env!("LOOM_PG_TARBALL"))`** + **`const PG_VERSION: &str = env!("LOOM_PG_VERSION")`** — both env values are plain strings (a `$(location)` and the `PG_VERSION` constant). Do NOT use a `select()` inside the `env` dict (no precedent in this tree).
- **Cache key is `pg-<PG_VERSION>`** (e.g. `pg-17.9.0`) — no runtime hashing of the 11.7 MB, no content sha.
- **libxml2 is NOT embedded** — system/deploy-provided. The dist tarball's own `lib/` (ICU etc.) IS embedded+extracted. In the test, `ld_library_path` = `<extracted lib>:<POSTGRES_LD_LIBRARY_PATH>` (the fixture env supplies the `:libxml2` shim, since RE/Arch lack system `.so.2`).
- **PR-b does NOT touch `service_runtime`/`build_pool_managed`** — the integration belongs to slice 3 (wiring `extract_pg` into the shared runtime would pull 11.7 MB into every service binary).
- **`:postgres-tarball` reuses the existing `PG_VERSION`/`_PG_URL`/sha pins** in `src/control-plane/postgres/BUCK` — one source of truth.
- **Tests are `rust_test` only** (sibling `tests/*.rs` wired in BUCK), never inline `#[cfg(test)]`. PG-booting tests use `loom_fixture_test`. Don't pipe `buck2 test` through `tail`/`head` — redirect to a file and grep.
- **After any `Cargo.lock` change** (adding `tar`/`flate2`): per CLAUDE.md, run `./tools/buckify.sh`, diff the lock vs the merge-base for native/`links` crates (`zstd-sys`, `ring`), and run the full `buck2 test //src/...` (reindeer re-resolution can churn unrelated crates). `tar`/`flate2` are pure-Rust (no `links`); no fixup expected.

use std::path::{Path, PathBuf};

/// Where the extracted, ready-to-exec PG distribution lives.
#[derive(Debug, Clone)]
pub struct ExtractedPg {
    /// `<cache>/pg-<version>/bin` (holds initdb, postgres, pg_ctl).
    pub bin_dir: PathBuf,
    /// `<cache>/pg-<version>/lib` (the dist's bundled libs; NOT libxml2).
    pub lib_dir: PathBuf,
}

#[derive(Debug, thiserror::Error)]
pub enum EmbedError {
    #[error("io: {0}")]
    Io(#[from] std::io::Error),
}

/// Extract the embedded PG distribution under `cache_root`, reusing an existing
/// `pg-<version>` extraction. Lock-free and concurrency-safe: a fresh extraction
/// goes to a per-pid temp dir and is published with an atomic `rename`.
pub fn extract_pg(cache_root: &Path) -> Result<ExtractedPg, EmbedError> {
    let final_dir = cache_root.join(format!("pg-{PG_VERSION}"));
    if !final_dir.exists() {
        std::fs::create_dir_all(cache_root)?;
        let tmp = cache_root.join(format!("pg-{}.tmp.{}", PG_VERSION, std::process::id()));
        // Re-run-safe: clear any stale temp from a previous crashed pid-reuse.
        if tmp.exists() {
            std::fs::remove_dir_all(&tmp)?;
        }
        std::fs::create_dir_all(&tmp)?;

        let gz = flate2::read::GzDecoder::new(PG_TARBALL);
        let mut archive = tar::Archive::new(gz);
        archive.set_preserve_permissions(true);
        for entry in archive.entries()? {
            let mut entry = entry?;
            let path = entry.path()?.into_owned();
            // Strip the single wrapping `postgresql-<ver>-<triple>/` component.
            let stripped: PathBuf = path.components().skip(1).collect();
            if stripped.as_os_str().is_empty() {
                continue;
            }
            entry.unpack(tmp.join(stripped))?;
        }

        // Publish atomically. If we lost a race, another process already
        // published a complete dir — discard ours and use theirs.
        match std::fs::rename(&tmp, &final_dir) {
            Ok(()) => {}
            Err(_) if final_dir.exists() => {
                std::fs::remove_dir_all(&tmp).ok();
            }
            Err(e) => return Err(EmbedError::Io(e)),
        }
    }
    Ok(ExtractedPg {
        bin_dir: final_dir.join("bin"),
        lib_dir: final_dir.join("lib"),
    })
}
```

//! Proves boot-from-embedded-bytes: extract the embedded PG distribution, then
//! boot EmbeddedPg against the EXTRACTED bin dir (NOT POSTGRES_BIN_DIR) and
//! accept a connection. libxml2 is supplied via the fixture's
//! POSTGRES_LD_LIBRARY_PATH (RE/Arch lack a system .so.2); production relies on
//! the system copy.

use managed_postgres::{EmbeddedPg, EmbeddedPgConfig};
use managed_postgres_embed::extract_pg;
use sqlx::postgres::PgPoolOptions;

#[tokio::test]
async fn boots_from_embedded_distribution() {
    let tmp = tempfile::tempdir().expect("tempdir");
    let cache = tmp.path().join("cache");
    let extracted = extract_pg(&cache).expect("extract");

    // Dist libs from the extraction + the fixture's libxml2 shim.
    let shim = std::env::var("POSTGRES_LD_LIBRARY_PATH").unwrap_or_default();
    let ld = format!("{}:{}", extracted.lib_dir.display(), shim);

    let cfg = EmbeddedPgConfig {
        bin_dir: extracted.bin_dir.clone(),
        ld_library_path: ld,
        data_dir: tmp.path().join("pgdata"),
        socket_dir: tmp.path().join("pgrun"),
        database: "loom".to_string(),
    };

    let pg = EmbeddedPg::start(cfg).await.expect("start from embedded dist");
    let pool = PgPoolOptions::new()
        .connect_with(pg.connect_options())
        .await
        .expect("connect");
    let one: i32 = sqlx::query_scalar("select 1")
        .fetch_one(&pool)
        .await
        .expect("select 1");
    assert_eq!(one, 1);
    pool.close().await;
    pg.shutdown().await.expect("shutdown");
}
```
